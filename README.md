# commute-check

Logbook for the ML team's weekly "coffee walk" — every week one of us picks a café near the
office and the whole team walks over together.

Since we don't want to run any server, the run history of the manually-triggered workflow
at `.github/workflows/commute-check.yml` doubles as the log: each run records the venue, the walking distance in km, and the walking duration in minutes for that week.
